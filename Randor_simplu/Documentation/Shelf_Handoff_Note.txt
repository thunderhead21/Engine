# 🎯 Why This Engine Exists

This engine is built from first principles.

The objective is **not** to imitate Unreal, Unity or other engines, but to construct a simulation framework that is:

* understandable
* architecturally coherent
* predictable
* pleasant to extend

Every abstraction must justify its existence.

---

# 🧠 Core Philosophy

Before writing code, always ask:

* ❓ **What is it?**
* 👤 **Who owns it?**
* ⚠️ **Am I introducing two truths?**

The answers to these questions determine the correct architecture.

---

# 🌍 Ownership Hierarchy

```text
Engine
│
├── Timer
├── InputManager
├── Renderer
└── Scene
      │
      ├── Physics
      └── Entities
            │
            ├── Transform
            ├── Mesh
            ├── Layers
            ├── Tags
            └── Name / ID
```

Ownership intentionally flows downward.

Responsibilities should not casually migrate between levels.

---

# 📦 Responsibilities

## Engine

Coordinates the application.

Owns the application's lifetime.

Orchestrates systems.

Does **not** implement subsystem logic.

---

## Scene

Represents the simulated world.

Owns:

* Physics
* Entities

Assigns world identity (IDs).

Coordinates updates.

Does **not** perform physics itself.

---

## Physics

Simulates the world.

Consumes Scene state.

Updates Entity transforms.

Owns **no** world objects.

---

## Entity

Represents something that exists within the world.

Owns:

* Transform
* Mesh
* Layers
* Tags
* Name
* ID

Does not perform rendering or physics.

---

## Transform

The authoritative spatial representation.

Position.

Rotation.

Scale.

Everything derives from Transform.

---

## Mesh

Geometry only.

Never owns:

* Transform
* Physics
* Gameplay
* Names
* IDs

Stores local-space geometry.

---

## Renderer

Observes the world.

Consumes Entity state.

Rendering never becomes simulation.

Simulation always drives rendering.

---

## InputManager

Interprets input.

Window owns SDL events.

InputManager never owns the operating system event queue.

---

# 🏷️ Object Creation

```text
Mesh::cube()

↓

Entity::cube()

↓

Scene::add_entity()
```

Mesh creates geometry.

Entity gives semantic meaning.

Scene assigns world identity.

Example naming:

```text
Cube_4
RigidBody_2
Entity_17
```

---

# 🧭 Mental Model

Always think:

```text
World
    owns
Entities
    own
Representation
```

Never:

```text
Renderer
      ↓
Gameplay
```

The simulated world is reality.

Everything else observes it.

---

# 🚫 Architectural Invariants

Never violate these without an intentional redesign.

* Transform is the **single source of truth** for spatial state.
* Mesh never owns transforms.
* Physics never owns world objects.
* Renderer never owns simulation.
* Avoid duplicated ownership.

If synchronization becomes necessary,

**question the ownership model first.**

Architecture compounds.
