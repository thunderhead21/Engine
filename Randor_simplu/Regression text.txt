SOLUTION

Current renderer rebuilds every frame:

Mesh (local)
      │
Transform
      │
World vertices
      │
Projection
      │
SDL_Vertex
      │
Render

Potential future optimization:

Mesh
      │
Transform
      │
VertexBuffer
 ├── world_vertices
 └── render_vertices

Rebuild only when invalidated.

Possible API:

vertex_buffer.invalidate();
vertex_buffer.rebuild();
vertex_buffer.up_to_date();

Typical invalidation sources:

Transform changed
Mesh changed
Projection parameters changed
Viewport resized

This avoids rebuilding world/projection buffers every frame for static geometry.
